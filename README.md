# Manhal Studio

Website portofolio jasa desain grafis dengan HTML, CSS, dan JavaScript.

## Struktur folder
- `index.html` — halaman website
- `style.css` — tampilan dan responsif
- `script.js` — navigasi, preview portofolio, dan WhatsApp
- `assets/` — gambar PNG `portofolio1.png` sampai `portofolio22.png`

## Gambar portofolio
Simpan gambar PNG di folder `assets` dengan nama `portofolio1.png`, `portofolio2.png`, dan seterusnya hingga `portofolio22.png`.

## Kontak WhatsApp
Tombol WhatsApp telah diatur ke nomor 0831-3852-4282. Nomor tersebut menggunakan format internasional `6283138524282` pada tautan WhatsApp.

## GitHub Pages
Unggah `index.html`, `style.css`, `script.js`, dan folder `assets` ke root repository. Lalu buka **Settings → Pages**, pilih **Deploy from a branch**, pilih branch `main` dan folder `/(root)`, kemudian simpan.


## Logo Manhal Studio
- `assets/logo-mark.png` digunakan pada navbar dan footer.
- `assets/logo-manhal.png` adalah logo lengkap dengan latar transparan.
Pastikan folder `assets` diunggah bersama file website agar logo tampil.
